НОРКА ДЛЯ GODOT 4: две карты (снаружи и внутри). Без зайчика.

КАРТА 1. СНАРУЖИ (burrow_outside.tscn), вид сбоку, ширина 640 px
  out_01_sky.png    небо с луной            motion_scale x = 0     320 x 180
  out_02_far.png    дальний лес             motion_scale x = 0.12  362 x 180
  out_03_mid.png    средний лес             motion_scale x = 0.30  420 x 180
  out_04_back.png   деревья позади          motion_scale x = 0.55  500 x 180
  out_05_main.png   земля, холм с норкой, дерево, гнездо, грядка, фонарь  motion_scale x = 1  644 x 180
  out_06_front.png  передний план (ствол, трава, листва, поверх игрока)  motion_scale x = 1.35  756 x 180
  Зайчик просыпается в гнезде из листьев (x = 300) и идёт к входу в норку (x = 400).

КАРТА 2. ВНУТРИ (burrow_inside.tscn), один экран 320 x 180
  in_01_room.png   комната: кровать, стол с лампой, полка, окно, ковёр, дверь слева
  in_02_front.png  передний план: корни с потолка, земля по краям (поверх игрока)
  Выход: дверь слева (x = 34). Кровать справа (x = 254).

burrow_data.json
  outside: координаты гнезда и входа, ground_y[x] (высота пола для x от 0 до 640)
  inside:  floor_y 150, door_x, door_spawn_x, bed_x, walk_range_x, bed_lie_y (где лежит зайчик на кровати)

Как подключить
  1. Скопируй папку burrow_layers в корень проекта (res://burrow_layers).
  2. Project Settings: Viewport 320 x 180, Window Override 1280 x 720,
     Stretch Mode = viewport, Default Texture Filter = Nearest.
  3. Две сцены: burrow_outside.tscn и burrow_inside.tscn. Игрока ставь между
     фоном и передним планом (у фона слой -1, у переднего плана слой 1).
  4. Вход в норку: когда игрок рядом с x = 400 на карте 1 и нажал "действие",
     делаешь затемнение и change_scene_to_file("res://burrow_inside.tscn").
     Спавн внутри: x = 50, y = 150. Выход: игрок у двери x = 34, спавн снаружи x = 410.
  5. Сон: игрок у кровати (x = 254) жмёт "действие", идёшь к x = 252 и
     ставишь спрайт сна на y = 126 (bed_lie_y). Для затемнения комнаты
     добавь ColorRect поверх с прозрачностью около 0.5.
  6. Camera2D снаружи: Limit Left 0, Right 640, Top 0, Bottom 180. Внутри камера не нужна.

Чего нет в PNG: светлячки, туман, листопад, свечение (лампа, грибы, кристаллы, фонарь,
вход в норку), луч света из окна, пылинки. Это анимируется в HTML-версии
(rabbit-burrow.html), в Godot делается через PointLight2D, GPUParticles2D или шейдер.
Свечение на картинках нарисовано статично только там, где оно часть предметов.
